# Security Policy

## Supported version

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

For vulnerabilities involving prompt injection, unintended local-file access, secrets or credential exposure, unsafe command execution, data exfiltration, or private evidence leaving the local machine, use GitHub's private vulnerability reporting:

<https://github.com/foxbitcoo/driving-justice/security/advisories/new>

Do not attach real traffic videos, clear license plates, faces, identity documents, phone numbers, cookies, tokens, or generated `ledger.xlsx` files to a public Issue.

For non-sensitive bugs, use:

<https://github.com/foxbitcoo/driving-justice/issues>

Include the Skill version, host/model capability summary, expected behavior, actual behavior, and a public-safe description of the input. Replace all identifying details with synthetic placeholders.
