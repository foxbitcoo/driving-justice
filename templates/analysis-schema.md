# 候选识别结果（Excel）

该文件定义博主试水/素材初筛模式的单一交付物 `analysis.xlsx`。它不是官方举报表单，也不等同于已提交举报的 `ledger.xlsx`。

## 输入与输出

- 输入：一段本地视频，或一张/多张本地图片。
- 输出：一个本地 `.xlsx` 文件，候选事件每行一条，证据图片直接嵌入单元格。

## 列

| 列 | 规则 |
|---|---|
| 序号 | 从 1 开始自增 |
| 素材文件 | 本地原始文件名 |
| 开始时间 / 结束时间 | 候选时间段，不是官方认定时间 |
| 候选违法行为 | 只写“候选”，不写已认定 |
| 车辆类型 / 车辆颜色 | 画面可见的粗略描述 |
| 车牌号 | 仅当模型结构化判断通过清晰度、轨迹和帧引用校验后才写；正式举报前仍需用户确认 |
| 证据状态 | 待人工复核、证据不足或模型判定车牌与轨迹通过（待人工复核） |
| 证据说明 | 说明画面能支持什么、不能支持什么 |
| 证据图1—5 | 嵌入的关键帧缩略图 |
| 证据帧标识 | 原素材文件名+时间点；不写入会随临时目录删除而失效的抽帧路径 |
| 模型链路 | 本次实际使用的模型 ID |
| 备注 | 人工确认面别或其他不确定项 |

## 模型车牌判断 JSON（离线测试示例）

```json
{
  "events": [{
    "event_id": "event-001",
    "model_plate_decision": {
      "plate_number": "粤B12345",
      "plate_side": "rear",
      "plate_fully_clear": true,
      "trajectory_continuous": true,
      "plate_frame_ids": [
        "clip-review-001-f000010",
        "clip-review-001-f000011"
      ],
      "incident_frame_ids": ["clip-review-001-f000018"],
      "independent_consensus": {
        "passed": true,
        "plate_number": "粤B12345",
        "plate_side": "rear",
        "frame_ids": [
          "clip-review-001-f000010",
          "clip-review-001-f000011"
        ]
      }
    }
  }]
}
```

两个布尔字段任意一个不是 `true`、车牌格式不合法、帧引用不存在、引用跨素材，或独立重读未逐字一致时，脚本都不得写入车牌。视频的独立重读至少需要两帧；单张图片可在独立复核该图后通过。DeepSeek 只接收 `plate_ref`，不能生成或改写车牌字符。
