# 举报陈述写作规范

用于 Step 7。陈述只写视频/图片能证明的事实，不加主观评价、不推测动机、不使用情绪化用词（禁用词例如"故意""恶意""变态""无良""肆意"——即使行为看起来确实如此，也只描述可观察的动作，定性交给条款本身和当地部门）。

## 结构模板

```
【发生时间】YYYY-MM-DD HH:MM（或视频拍摄时间戳对应的时段）
【发生地点】XX市XX区XX路与XX路交叉口（用户确认过的地点，不是模型自行猜测的地点）
【涉事车辆】车牌号 XX·XXXXX；车辆类型/颜色（例如：黑色轿车）；行驶方向（例如：由南向北）
【违法行为】用一到两句话描述可观察的动作，不加评价词。
  例：该车在与行人同向近距离交会时持续使用远光灯，未切换为近光灯，直至驶离拍摄范围。
【法律依据】《XX法》第XX条：""（现场核验到的条款原文摘录，附官方链接）
  若该行为未找到直接对应条款：注明"该行为暂无直接对应条款，建议由当地部门认定具体适用依据"。
【证据说明】视频/图片文件名 + 对应时间段（例如：dashcam_0728.mp4 第 12 秒—第 27 秒），关键帧文件路径列表。
```

## 示例

```
【发生时间】YYYY-MM-DD HH:MM
【发生地点】XX市XX区XX路与XX路交叉口（用户确认）
【涉事车辆】车牌号 XX·XXXXX；黑色轿车；等候红灯，车头朝向XX路南向
【违法行为】该车在等待红灯期间持续使用远光灯照射行人方向，未切换为近光灯，直至绿灯放行驶离。
【法律依据】《中华人民共和国道路交通安全法》第四十八条：机动车在夜间行驶……不得使用远光灯（此处以现场核验到的现行原文为准）。参考链接：flk.npc.gov.cn 对应条目
【证据说明】example.mp4 第 12 秒—第 27 秒；关键帧：frame_glare.jpg（远光灯照射瞬间）、frame_visible_plate.jpg（清晰前牌或后牌）、frame_track.jpg（连接车牌帧与违法瞬间的连续轨迹）
```

## 写完之后

生成的陈述先给用户看一遍，用户确认无误（尤其是地点、车牌、时间是否准确）之后，才把这段文字填入官方表单对应的描述字段。不要自行精简或改写用户已经确认过的版本。
