# 本地台账字段结构（Excel）

本地 `ledger.xlsx` 是用户自己保存和查看的证据台账，不是 12345、交警专项渠道等官方举报平台的表单。

Step 9 分为两个动作：

1. 官方举报表单预填完成后，用 `scripts/append_ledger.py` 先把记录写入本地 `ledger.xlsx`（首次运行自动创建，带表头），状态记为“已预填待用户提交”
2. 用户手动提交官方表单后，用 `scripts/update_ledger.py` 更新同一条记录的举报单号和状态，不新增第二行

新增脚本的输入是一份 JSON，字段如下：

| JSON 字段 | 对应表格列 | 说明 |
|---|---|---|
| 举报时间 | 举报时间 | 建议格式 `YYYY-MM-DD HH:MM` |
| 视频文件名 | 视频文件名 | 原始素材文件名 |
| 发生地点 | 发生地点 | 用户确认过的地点，不是模型自行猜测的 |
| 违法行为 | 违法行为 | 对应 `references/traffic-law.md` 里的行为名称 |
| 法律依据 | 法律依据 | 法律名称+条款号（Step 3/7 现场核验后的结果） |
| 车牌号 | 车牌号 | 只在通过 `plate-verification.md` 硬闸门后才填，否则整条记录先不建 |
| 车辆类型 | 车辆类型 | 例如"轿车""SUV""货车" |
| 车辆颜色 | 车辆颜色 | |
| 证据图片 | 证据图1~证据图5 | **数组**，元素是关键帧图片的本地文件路径，按顺序嵌入到"证据图1"…"证据图5"列；超过 5 张，多出的仍会记录在"原始证据文件路径"列，但不嵌入缩略图 |
| （自动）| 原始证据文件路径 | 脚本自动用"；"拼接"证据图片"数组里的所有路径，保留完整追溯链，不受缩略图数量上限影响 |
| 举报渠道 | 举报渠道 | 例如"珠海12345在线举报" |
| 举报单号 | 举报单号 | 如果官方渠道提交后返回了单号，用户提供后补填；没有就留空 |
| 举报状态 | 举报状态 | 例如"已预填待用户提交""已提交待处理""已处理" |
| 备注 | 备注 | 其他需要说明的信息 |

## 示例 entry.json

```json
{
  "举报时间": "2026-07-28 21:47",
  "视频文件名": "dashcam_0728_2145.mp4",
  "发生地点": "珠海市高新区唐家湾镇情侣北路与全岛环路交叉口",
  "违法行为": "不当使用远光灯/会车炫目",
  "法律依据": "《道路交通安全法》第四十八条",
  "车牌号": "TEST-PLATE",
  "车辆类型": "轿车",
  "车辆颜色": "黑色",
  "证据图片": ["frame_glare.jpg", "frame_front_plate.jpg", "frame_pass.jpg", "frame_rear_plate.jpg"],
  "举报渠道": "珠海12345在线举报",
  "举报单号": "",
  "举报状态": "已预填待用户提交",
  "备注": ""
}
```

## 调用方式

```bash
pip install openpyxl pillow   # 首次使用前安装依赖
python scripts/append_ledger.py --entry entry.json --ledger ledger.xlsx
```

`ledger.xlsx` 默认生成在 Skill 根目录，用户也可以通过 `--ledger` 指定其他路径。

## 提交后更新同一条记录

用户手动提交官方举报表单并获得举报单号后，创建一份更新 JSON，例如 `update.json`：

```json
{
  "举报单号": "ZH202607290001",
  "举报状态": "已提交待处理",
  "备注": "用户已完成最终提交"
}
```

然后按本地台账中的“序号”更新原记录：

```bash
python scripts/update_ledger.py --seq 1 --updates update.json --ledger ledger.xlsx
```

更新脚本只允许修改“举报渠道”“举报单号”“举报状态”“备注”四个字段。序号不存在、序号重复、更新文件为空或包含其他字段时，脚本会停止且不保存文件。车牌、违法事实、法律依据和证据图片不能通过此脚本改动。
