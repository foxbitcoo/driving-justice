# 常见违法行为与法律依据对照表

用于 Step 3 违法行为定性。本表覆盖行车记录仪/手机拍摄场景中最常见的几类"轻量级、无需交警到场"的违法行为，定位是**随手举报的初筛**，依据现行《中华人民共和国道路交通安全法》及其实施条例。**具体处罚金额、记分标准各省市可能有细则差异**，表中条款仅用于定性和引导核验，不要把处罚数字当作确定结论直接写进举报陈述或告知用户为最终处罚。

| 违法行为 | 视频中的判定线索 | 主要法律依据（条款号，需核验原文） | 说明 |
|---|---|---|---|
| 不当使用远光灯 / 会车炫目 | 对向或同向车辆在近距离持续使用远光灯，未切换近光 | 《道路交通安全法》第四十八条；实施条例第五十八条 | 需能看清对方车辆确实处于会车/近距离场景，且远光灯持续时间足够长，偶尔一闪不足以认定 |
| 闯红灯 | 信号灯为红色时车辆越过停止线继续通行 | 《道路交通安全法》第四十四条；实施条例第三十八条 | 需要同时看清信号灯状态和车辆越线瞬间，两者缺一不可 |
| 逆向行驶 | 车辆行驶方向与本车道规定方向相反 | 《道路交通安全法》第三十五条 | 需确认车道方向标识或对向车流以排除单行道临时管制等特殊情况 |
| 违法变道 / 加塞 | 未提前使用转向灯、未保持安全距离强行并入车道 | 《道路交通安全法》第四十四条 | 主观描述"恶意"不可用，只描述动作：是否打灯、间距是否足够 |
| 违法停车 | 在禁停标线、消防通道、人行道等区域停放 | 《道路交通安全法》第五十六条 | 需能看清具体的禁停标识或标线 |
| 压实线 / 压导流线 | 车轮压在白色实线、黄色网格线、导流线上行驶或变道 | 《道路交通安全法》第三十八条；实施条例第三十九条 | 需看清标线类型（实线/虚线/导流线不同，条款和处罚可能不同），偶尔轻微压线但迅速纠正的边界情况要谨慎定性 |
| 不礼让斑马线行人 | 行人已在斑马线上，车辆未停车避让径直通过 | 《道路交通安全法》第四十七条 | 需看清行人已进入斑马线，而非行人尚在路边等待 |
| 驾驶时使用手机 | 驾驶员手持并操作手机 | 实施条例第六十二条第（五）项 | 需要能看清驾驶员动作，仅看到手部靠近耳边不足以认定 |
| 占用应急车道 | 非紧急情况下车辆行驶或停放在应急车道 | 实施条例第八十条 | 需排除故障停车、避险等合理场景 |
| 货车违反车道通行规定 / 驶入小客车专用车道 | 车道上方或路侧交通标志明确标示“小客车”或货车禁行，且目标车辆可从连续画面中的完整车身结构明确识别为载货汽车，并持续驶入或占用该车道 | 《道路交通安全法》第三十七条、第三十八条；当地交通管理措施或公告（如有） | 必须同时拍到适用于该车道的交通标志和目标车辆；只看到车辆位于左侧车道、或仅凭车辆大小不能认定。道路类型、标志效力、具体违法代码和处罚标准由当地公安交管部门认定 |
| 故意压水花溅行人 | 路面有明显积水，车辆靠近行人一侧且未减速通过，行人被溅湿/明显有躲避动作 | **没有直接对应的单一条款**，通常归入实施条例中"妨碍安全行车的其他行为"一类兜底条款，具体适用条款和是否受理**必须每次现场核实**，不要沿用固定条款号 | 需能看清路面积水、车辆未减速的动作，以及行人被溅或躲避的反应；单纯"车辆经过积水"不足以认定为"故意" |

## 现场核验官方原文（每次生成陈述前必做）

上表里的法律名称和条款号是相对稳定的知识，可以直接用于初筛定性，但**不要把条款原文当作已知信息直接写进最终举报陈述**——法条可能被修订，原文必须每次现场核对：

1. 用 WebSearch/WebFetch 检索"国家法律法规数据库 道路交通安全法"，进入官方网站 `flk.npc.gov.cn` 查找对应条款的现行原文
2. 把核验到的**条款原文摘录**和**官方链接**一并记录下来，用于 Step 7 生成陈述时引用
3. 如果核验发现表中条款号已变化或条款内容与预期不符，以核验到的现行原文为准，并告知用户"条款已更新，以下为当前有效版本"
4. 找不到官方原文、或该行为确实没有直接对应条款（例如"压水花"）时，如实在陈述中标注"具体适用条款请当地部门认定"，不要编造条款号或原文

## 不适用本表的情况

- **酒驾/醉驾、肇事逃逸、涉嫌危险驾驶**等涉及人身安全的严重情形：告知用户应直接拨打 110 或联系交警现场处理，不适用本 Skill 面向的 12345/在线举报流程。
- 表中未覆盖的行为，或对条款适用有争议的场景：如实告知用户"具体条款需要人工核实"，可建议用户直接咨询当地交警热线确认，不要编造条款编号。
